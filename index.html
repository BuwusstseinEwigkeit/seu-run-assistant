    从 SEU 登录到 Token
    1. 打开并登录 SEU 运动平台

      入口只负责学校身份认证。如果校外连接被中止，请先使用能访问校内服务的网络。

    2. 打开浏览器开发者工具

      在电脑浏览器中按 F12，根据上方第 2 张原项目截图查看控制台请求信息。

    3. 定位 Token 字段

      展开 request res========，找到 request.headers.token。

    4. 复制并返回本页

      复制完整值，不要包含字段两侧引号。Token 形如 Bearer [part1].[part2].[part3]。

    填写、检查、提交
    01 填写基础信息

    粘贴 Token，选择场地、开始时间与结束时间。

    02 准备照片

    分别上传开始和结束照片，并先查看页面预览。

    03 执行本地预检

    检查 Token 形态、时间范围、照片与可选课表冲突。

    04 阅读结果再判断

    最后一步才发起请求；以页面返回的明确结果为准。
