    用本地工具获取 Blade-Auth Token
    1. 1. 启动本地桥接服务

      先双击 tools/token-tool/get-token.bat。黑色窗口必须保持打开；网页无法代替浏览器安全地自动运行 .bat。

    2. 2. 打开微信小程序

      进入“东南大学体育管理 → 阳光跑”，打开会加载数据的页面，让小程序发起请求。

    3. 3. 点击网页提取 Token

      点击首屏“从微信小程序提取 Token”，桥接服务会把微信进程中的 Blade-Auth Token 回填到输入框。

    4. 4. 确认 Token 已填入

      输入框会自动填入 Token，桥接服务同时复制一份到剪贴板作为备用。填入后页面会立刻校验，并从服务端拉取当前场地与规则。

    桥接窗口在整个使用过程中都要保持运行：提取 Token 靠它读微信进程内存，提交记录也要经它转发——服务端的跨域白名单不允许浏览器直接调用小程序接口。

    填写、检查、提交
    01 填 Token 并选场地

    粘贴 Blade-Auth Token，选择运动场地。Token 校验通过后，场地与规则会从服务端实时刷新。

    02 一键生成时间与轨迹

    点“一键生成时间+轨迹”：先按规则配速反推距离生成轨迹，再用轨迹长度算出时长，并安排在规定的锻炼时间内。三者始终自洽，也可手动改。

    03 准备照片并预检

    上传开始和结束照片后执行本地预检：Token 形态、时间范围、照片、当天是否已有记录，以及可选的课表冲突。

    04 阅读结果再判断

    提交期间页面会显示检查、上传和等待状态；以明确成功提示为准。
